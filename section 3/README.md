# Section 3 · Definable sets in VF

Run `lake build` in this folder. Import `Section3` to use its declarations.
Lake uses the sibling Section 2 package and its pinned Mathlib revision.
The ordinary base is a fixed two-sorted substructure. Results involving extra
disc codes specify the extra parameter family. As in Section 2, valued-field
discs use Mathlib's multiplicative valuation, so a smaller radius denotes a
smaller disc.

| 3.29, 3.31, 3.33 | `RegularPoints`, `Orientation`, `PartialDerivatives`, `GoodLabels`, `NormalizedSlice` | At order zero the regular locus consists of continuity points. | 3.34 | `AffineLine`, `ExponentialObstruction` | Equal profiles at two origins give a translation conjugate to a dilation. In fact the affine map must be a translation because a nontrivial dilation cannot have a fixed point on the ray. Common profiles give an injective exponential. O-minimality gives a supremum to every nonempty bounded definable unary set. If the exponential E were bounded by a definable power g, the positive ratio E(x)/g(x) on a large positive tail would have a supremum. Doubling x more than doubles that ratio there. This contradicts the supremum. The normalized graph of an increasing line-to-ray chart is definable, and its range gives cofinality. Thus common profiles contradict the Section 2 definition of power boundedness. |
