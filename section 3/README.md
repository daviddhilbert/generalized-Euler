# Section 3 · Definable sets in VF

Run `lake build` in this folder. Import `Section3` to use its declarations.
Lake uses the sibling Section 2 package and its pinned Mathlib revision.
The ordinary base is a fixed two-sorted substructure. Results involving extra
disc codes specify the extra parameter family. As in Section 2, valued-field
discs use Mathlib's multiplicative valuation, so a smaller radius denotes a
smaller disc.

## Calculus and the external inputs

`ValueChartLocus` defines the common open locus of constant jet values by quantifying the corners of an open box over the original parameters. `SmoothSlices` and `AdjacentCharts` prove the full unary comparison on that locus, including identically zero jets. `ContractedJets` restricts to a coordinate interval through each label, applies the comparison and proves integrality for every jet by induction. `CollapsedResidueBranch` proves that the strict-value case of 3.30 gives one constant on the whole projected interval. `IteratedRV` proves the nonvanishing iterated RV identity in every nonzero chart when no adjacent derivative vanishes or drops in magnitude. `IteratedReduction` identifies the residue values with actual iterated order derivatives for every ordering of the differentiations. `SmoothDomain` identifies the RV-image of the nonsmooth field locus with its RV-boundary and constructs the initial open domain by combining the lower-dimensional exceptions for the field, partials and residue charts. `DifferentialPolynomial` applies the construction to all variables of the operator at once, with varying contractible coefficients and with an exceptional set definable over the given base.

`RegularOrientation` proves the dimension bound in 3.29 from smooth constant-rank patches and the deficient-rank fiber conclusion of the constant rank theorem. For 3.33 it transfers the strict determinant sign to every field representative over each surviving label. Its external orientation input is the cited o-minimal theorem for a continuous locally injective map on a definably connected open domain.

Lean declarations take the specific model-theoretic or o-minimal results they use as hypotheses. In particular, immediate comparison uses the Section 2 model and saturation inputs, value choice uses the induced unary value-group cells, and the calculus uses the pure-field mean value theorem on smooth pieces and o-minimal generic smoothness.
